# v0.1.1 release checklist

- Add a GUI action that generates a strong connection key without requiring a terminal command.
- Publish a GitHub Release named `v0.1.1` with concise English and Traditional Chinese notes.
- Add CI for type checking, tests, build, and a secret scan.
- Add GitHub Topics for PWA, Hermes Bot, local AI, Tailscale, and mobile agents.
- Productize the README opening section with a clear value statement, quick-start path, and synthetic product previews.
- Create a synthetic chat preview that prominently shows a Bot response containing syntax-colored code. Do not use real profiles, conversations, URLs, keys, or personal data.
- Use AIOT's state glow consistently: muted green with a faint white halo for online, selected, and completed states; muted red for waiting/error/stop states. Respect reduced-motion settings.
- Measure event receive delay in the PWA and make polling visibility-aware. The current event loop waits 800 ms after each request and profile discovery refreshes every 30 seconds, so v0.1.1 should distinguish model time, network time, and client polling delay before changing transport behavior.

Task/workflow cards are excluded from v0.1.1: the current Bot API does not expose structured task or schedule state. Genuine approval cards remain supported.
