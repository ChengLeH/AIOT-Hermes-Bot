# AIOT / Hermes Bot v0.2.1

## English

AIOT v0.2.1 makes Bot and Session work safer to continue from a phone. Text sent while a turn is active enters a real FIFO queue, generated Session files and images are exposed through authenticated downloads, and the single composer action changes between Send and Stop without adding another mobile control.

Completed independent and forked Sessions now mark their parent Bot with the existing blue unread badge. Chrome also repairs stale Push subscriptions automatically when the local notification key changes. Scheduled jobs use the same compact, immediate accordion behavior as the queue, deliver new results through Hermes 0.21.1's official canonical Bot Chat route, and can be deleted without a browser-native confirmation dialog. Deleting an active job waits for Hermes to pause it before deletion.

The release also closes two trust boundaries: completed Session results return to the parent Bot only as explicitly untrusted JSON reference data, and attachment preview URLs are isolated by connection and task scope. Browser credentials and host-side run/task/push state remain AES-256-GCM encrypted with fail-closed migration behavior.

Setup is now the same small flow on macOS, Linux and Windows: run the included Start launcher, enter the existing Tailscale HTTPS Bot origin and connection key, then sign in to the official Hermes Dashboard only when first using Session tasks. AIOT does not install, restart or modify Hermes.

Validated locally with the complete test/type/lint/build suite and on Android PWA with a real queued Session pair and generated-file download. iPhone download-return layout recovery is scheduled for the next version. Windows is not yet claimed as verified; the Linux instructions are tested after publication on a separate host.

## 繁體中文

AIOT v0.2.1 讓手機上的 Bot 與 Session 更適合連續工作。回合執行中送出的文字會進入真正的 FIFO 佇列；Session 生成的圖片與文件可透過驗證後的端點預覽或下載；同一顆操作鍵會依輸入狀態切換傳送與停止，不增加手機介面負擔。

獨立與 Fork Session 完成後，父 Bot 會顯示既有的灰藍色未讀標籤。Chrome 遇到本機通知金鑰更新時，也會自動清除舊 Push 訂閱並重新註冊。排程工作改用和佇列一致的緊湊快速收合；新建排程會透過 Hermes 0.21.1 官方 canonical Bot Chat 路徑把結果送回指定 Bot。刪除不再跳瀏覽器原生確認框；執行中的排程會先等待 Hermes 暫停成功再正式刪除。

這版也補齊兩個信任邊界：Session 完成結果只會以明確標示為不可信的 JSON 參考資料回到父 Bot；附件 object URL 依連線與任務範圍隔離。瀏覽器憑證及主機端 Run／任務／推播狀態維持 AES-256-GCM 加密，遷移失敗時不會用預設值覆蓋。

macOS、Linux 與 Windows 共用簡化流程：執行內附的 Start 啟動程式，填入既有 Tailscale HTTPS Bot 網址與連線金鑰；只有第一次使用 Session 任務時才登入 Hermes 官方 Dashboard。AIOT 不會安裝、重啟或修改 Hermes。

本版已完成全部本機測試、型別、零警告 lint 與正式建置，並在 Android PWA 用真實 Session 驗證佇列接續與生成檔案下載。iPhone 關閉下載預覽後的版面恢復排入下一版；Windows 尚不列為已驗證，Linux 公開流程會在另一台主機於發布後實測。
