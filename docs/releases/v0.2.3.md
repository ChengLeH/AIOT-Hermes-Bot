# AIOT / Hermes Bot v0.2.3

## English

AIOT v0.2.3 completes the public release presentation and closes several persistence and lifecycle gaps found after v0.2.2.

- Active Session tasks now accept queued files and images. Attachment bytes stay inside the existing encrypted host task state, are bounded to 25 MiB in total, and are staged only when that queued turn begins.
- Selecting an attachment during an active Bot turn remains available and follows AIOT's existing default Fork task behavior.
- The encrypted native-run service preserves the Bot history reset marker across restarts, preventing older clients from replaying cleared history.
- Startup reclaims port 8888 only from a process positively identified as AIOT and refuses unrelated listeners.
- macOS users can optionally install a login service. Its LaunchAgent stores executable paths only; connection credentials remain in the existing private credential path.
- The project page now shows current, fictional-data previews for all major mobile surfaces instead of a few older partial screens.

The release candidate passed the complete automated test suite, type checking, zero-warning lint, production build, public-source scan, and isolated browser regression. Preview images were regenerated from the release candidate in a 390 × 844 mobile viewport. These synthetic previews demonstrate UI rendering only; they are not evidence of live Hermes execution or notification delivery.

Verified platform scope remains macOS host plus Android Chrome/PWA. Windows, a clean external Linux installation, live iPhone notification delivery, and the previously reported iPhone Session-completion white-screen path are not claimed as accepted by this release.

## 繁體中文

AIOT v0.2.3 補齊公開發行內容，並關閉 v0.2.2 發布後發現的幾個持久化與生命週期缺口。

- Session 任務執行中可繼續排入檔案與圖片。附件內容保存在既有的主機端加密任務狀態，總量限制為 25 MiB，並只在該輪真正開始時暫存到 Hermes。
- Bot 執行中仍可選擇附件，並沿用 AIOT 既有的預設 Fork 任務行為。
- 加密的 native-run 服務在重啟後仍保留 Bot 歷史清除時間，避免舊客戶端重新帶回已清除的紀錄。
- 啟動流程只會接手確認屬於 AIOT 的 8888 監聽程序；其他服務占用時會拒絕搶占。
- macOS 可選擇安裝登入服務。LaunchAgent 只保存執行檔路徑，連線憑證仍沿用既有的私人憑證路徑。
- 專案首頁改用目前版本及虛構資料產生的主要手機畫面，不再只放少量舊版局部截圖。

發行候選版通過完整自動測試、型別檢查、零警告 lint、正式建置、公開來源掃描及隔離瀏覽器回歸。預覽圖由候選版以 390 × 844 行動裝置尺寸重新產生；這些合成預覽只證明 UI 能正確渲染，不代表真實 Hermes 執行或通知投遞證據。

目前驗證平台仍為 macOS 主機與 Android Chrome／PWA。Windows、全新外部 Linux 安裝、iPhone 實機通知投遞，以及先前回報的 iPhone Session 完成後白畫面路徑，都不列入本版已驗收聲明。
